# Cryptocurrency Investment System

## 

## \Project Overview



The Cryptocurrency Investment System is a web application designed to manage cryptocurrency investments and digital financial transactions. It provides features for user registration, investment plans, wallet management, deposits, withdrawals, cryptocurrency exchange, transfers, payment processing, KYC verification, and transaction monitoring. The system includes an administrative dashboard for managing users, investments, transactions, reports, and system settings.



Technologies: PHP 8.3, MySQL, HTML, CSS, and JavaScript.



## \Included Functionality

* User registration, authentication, profiles and activity logging
* Administrator authentication and management dashboard
* Cryptocurrency/coin and currency management
* Wallets and balances
* Deposits and withdrawals
* Investment plans and investment positions
* Crypto marketplace and exchange records
* Transfers
* Payment gateways, payment methods and banks
* Gift cards and sales records
* Utility/bill modules for airtime, internet, cable TV and electricity
* Tickets, messages and support data
* KYC submissions
* Blog posts, categories, FAQs, testimonials, social links and services
* Reports and system settings
* Original database schema retained as the starting data model, with missing model tables added for native operation



## \Requirements

* PHP 8.3+
* MySQL 5.7+/8.x or MariaDB
* Apache/XAMPP
* PDO and PDO\_MySQL

## \Installation

1. Copy the project into `C:\\xampp\\htdocs\\Cryptocurrency\_Investment\_System`.
2. Start Apache and MySQL.
3. Create a MySQL database named `cryptocurrency\_investment` (or use the name configured through environment variables).
4. Open `http://localhost/Cryptocurrency\_Investment\_System/install.php`.
5. Enter an administrator account and install the schema.
6. Log in through `login.php`.

## \Database Configuration

Default connection values are: host `127.0.0.1`, port `3306`, database `cryptocurrency\_investment`, user `root`, blank password. Set `CIS\_DB\_HOST`, `CIS\_DB\_PORT`, `CIS\_DB\_NAME`, `CIS\_DB\_USER` and `CIS\_DB\_PASS` as environment variables when required.
